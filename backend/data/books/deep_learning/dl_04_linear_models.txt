TITLE: Linear and Logistic Models
---
Linear regression predicts a continuous value from weighted input features. The hypothesis is typically a dot product plus bias. Mean squared error is a common objective for regression tasks. Gradient-based updates reduce this loss iteratively.

Logistic regression predicts class probabilities for binary classification. The sigmoid function maps logits to values between zero and one. Binary cross-entropy is used as the training objective. Decision thresholds transform probabilities into class predictions.

These baseline models are important in deep learning pipelines. If a simple baseline beats a complex model, your architecture or data pipeline may be wrong. Always compare advanced models against well-tuned linear/logistic baselines.
