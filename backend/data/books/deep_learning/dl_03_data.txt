TITLE: Data Pipelines and Splits
---
Data quality controls model quality. A robust pipeline defines training, validation, and test splits before model tuning. Validation is used for model selection and hyperparameter tuning. Test data should remain untouched until final evaluation.

Data leakage occurs when information from validation or test sets influences training. Leakage creates inflated metrics and poor real-world performance. Common leakage sources include normalization using all data, label-derived features, and duplicated examples across splits.

Batching and shuffling influence optimization dynamics. Training batches are usually shuffled each epoch, while validation and test loaders should preserve deterministic ordering where possible. Monitoring class balance and label noise during ingestion prevents misleading training curves.
